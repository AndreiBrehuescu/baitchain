# Bait Chain

An early playtest build of a browser game in development. Every fish you catch becomes the bait for a bigger one: build a living chain down the food web and haul it up. Sail one open coast, from the Pond to the Reef, and visit the Port island.

Play: https://andreibrehuescu.github.io/baitchain/

This repository holds only the built game. Progress is saved in your own browser; nothing is collected.
